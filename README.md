Version **0.7.23-rc42 (78)** · ARM64 · Android 12 or later. Install over rc28 or a newer P2P Preview to keep your data. Older builds use the previous signing key.

P2P uses Chatmail for encrypted delivery and WebRTC for Talk. The toolbar includes a global mute bell. On the Talk screen, **Clear recent** clears the local call history after confirmation and keeps voicemail.

All 113 automated tests passed and Android lint reported zero errors. The signed APK passed signature and WebRTC startup packaging checks. Playback and call alerts still need physical-device verification.
