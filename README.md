# P2P for Android

[Download P2P 0.7.23-rc39 for Android](https://github.com/JustTrySomthing/P2P-Releases/releases/download/v0.7.23-rc39/P2P-0.7.23-rc39-ARM64-Preview.apk)

Version **0.7.23-rc39 (75)** · ARM64 · Android 12 or later. Install over rc28 or a newer P2P Preview to keep your data. Older builds use the previous signing key.

P2P uses Chatmail for encrypted delivery and WebRTC for Talk. In this preview, Settings and Contacts share one toolbar, the system bars have solid theme backgrounds, and cards match the neutral message bubble color. Empty folders and feeds use centered status bubbles.

All 110 automated tests passed, Android lint reported zero errors, and the signed APK passed its signature and WebRTC bootstrap checks. Layout and transitions still need a physical-device check on this build.
