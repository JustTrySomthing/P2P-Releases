# P2P for Android

Version **0.7.23-rc45 (81)** · ARM64 · Android 12 or later. Install over rc28 or a newer P2P Preview to keep your data. Older builds use the previous signing key.

P2P uses Chatmail for encrypted delivery and WebRTC for Talk. Contact invites now show a larger personalized QR card with **Copy code** and **Share** underneath. Long-press menus support reply reminders and other actions for conversations, messages, and Social posts.

All 115 automated tests passed and Android lint reported zero errors. The signed APK passed signature and WebRTC startup packaging checks. Live QR scanning between phones still needs physical-device verification.
