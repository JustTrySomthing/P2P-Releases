Version **0.7.23-rc37 (73)** · ARM64 · Android 12 or later.

Install over rc28 or a newer P2P Preview to retain your data. Older builds use the previous signing key.

P2P uses Chatmail for encrypted delivery and WebRTC for Talk. This preview includes encrypted backups, recent calls grouped by date, contextual contact actions, responsive Settings and dialogs, and visible Trash actions in Chats and Groups.

All 109 automated tests passed, Android lint reported zero errors, and the signed APK passed its signature and WebRTC bootstrap checks. Live calling and background delivery in this build still need physical-device testing.
