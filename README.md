Version **0.7.23-rc40 (76)** · ARM64 · Android 12 or later. Install over rc28 or a newer P2P Preview to keep your data. Older builds use the previous signing key.

P2P uses Chatmail for encrypted delivery and WebRTC for Talk. This preview adds inline media to Social posts, themed buttons for starting chats and groups, and separate mute bells for Chats, Groups, and Talk.

All 112 automated tests passed and Android lint reported zero errors. The signed APK passed signature and WebRTC startup packaging checks. Playback and call alerts still need physical-device verification.
